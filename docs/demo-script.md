# Shodh 2-Minute Demo Script

**0:00–0:15 — Opening**

“Shodh is a multilingual research assistant built around one principle: an answer is only useful if you can inspect the evidence behind it.”

**0:15–0:35 — Upload**

Open Upload. Drop in a PDF. Show the upload progress, then the ingestion status changing from processing to complete.

**0:35–0:50 — Corpus**

Open Documents. Show the filename, indexed chunk count, timestamp, and document ID.

**0:50–1:20 — Ask**

Open Chat. Select the document and ask an English question. Expand a citation card and show the page number, chunk ID, and supporting snippet.

Ask the same question in Hindi. Point out that the system detects the language and answers in that language while retrieving from the same multilingual corpus.

**1:20–1:40 — History**

Open the query history sidebar. Show that previous questions and answers remain attached to the document context.

**1:40–1:55 — Evaluation**

Open Evaluation. Trigger the golden-set run and show per-language RAGAS metrics plus the comparison chart.

**1:55–2:00 — Close**

“Shodh combines dense retrieval, BM25, reranking, multilingual embeddings, and citation-aware generation into one inspectable research workflow.”
